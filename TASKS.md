# TASKS.md — единая доска задач команды AND

Задача #79-lite: умный подбор подрядчиков. Разбор Задачи — в `CLAUDE.md`,
границы и допущения — в `SCOPE.md`, правила разработки — в `AGENTS.md`,
Положение — в `docs/POLOZHENIE.md`.

## Как пользоваться

1. Закрыл задачу — впиши в столбец **Статус** слово `done` и время: `done 14:35`.
2. Статус правится **в том же коммите**, что и сама задача. Отдельных коммитов «обновил доску» быть не должно.
3. Взял задачу в работу — впиши `в работе`. Так двое не возьмут одну.
4. Задача не нужна или отменена — `снято` и одной строкой почему.
5. Появилась новая задача — допиши строку в свой раздел, ID по порядку.

Владение папками не пересекается, поэтому конфликтов в git быть не должно:
**A** — `backend/agent/core/`, **B** — `frontend/` и `backend/agent/views.py`,
**C** — `docs/`, `README.md`, датасет.
