Проверка по README идёт без ключа, и объяснения там собирает код. Здесь — что на тех же
запросах пишет модель. Тексты скопированы из журнала запусков без правок; модель
`gpt-5.4-mini` через OpenAI API, 23.09.2026, 11:10–11:11 по времени машины разработчика.
Порядок карточек в каждом ответе задан кодом (`search_contractors`) и совпадает с порядком
без ключа: модель получила посчитанные факты и написала по ним текст.

Как это воспроизвести самим: вписать в `.env` `OPENAI_API_KEY` и `OPENAI_MODEL`, поставить
`LLM_MOCK=0`, перезапустить бэкенд и повторить запросы из таблицы README. Прогон на тех же
кейсах с автоматическими проверками (числа и цитаты присутствуют в JSON инструмента,
нет общих фраз, объяснения различимы) — `docs/EVAL.md`.
