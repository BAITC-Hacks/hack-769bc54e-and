# Почасовой журнал работы

Требование п. 5.4.8 Положения: у команды должен быть подтверждаемый промежуточный
результат по итогам **каждого** часа соревновательной части. Отсутствие результата за
любой отчётный час — основание для дисквалификации (п. 5.9.2).

Порядок: на отметке **:50** каждого часа — `make check`, коммит, пуш, строка в таблице
ниже, тег `git tag h<N> && git push --tags`. Тег нужен, чтобы прогресс читался в один
взгляд и эксперту не пришлось разбирать всю историю коммитов.

но коммиты в каждом часе есть. Теги `h1` и `h2` стоят на последнем коммите своего часа.

Промежуточным результатом считается (п. 5.4.8): изменения в коде или репозитории,
разработанный функционал, прототип, дизайн, схема архитектуры, настроенная модель,
проведённое тестирование, подготовленные данные или иное подтверждение прогресса.
То есть коммит с документом или датасетом тоже годится — но он должен быть.
