По пути закрываем вживую ещё два приёмочных теста жюри: «скрыть имена» (R14) и «две даты» (R16).
Запросы сверены с интерфейсом, прогон по таймеру — в конце раздела.

Не берём на демо лайв-бэнды и национальные ансамбли в Алматы: там есть почти одинаковые
профили, и их карточки со скрытыми именами не различить (`docs/DATASET_NOTES.md`, п. 1).

**Прогон по таймеру.** Сценарий пройден в интерфейсе дважды подряд, числа — ниже. Это время

прочитать вслух с секундомером.

Режим — без ключа (mock): ответ приходит со следующим опросом интерфейса, раз в секунду.
С настоящей моделью ответ дольше, до 5,2 с по `docs/EVAL.md`, — на сценарий это добавит
около 15 секунд, поэтому паузы в пунктах 2–6 держим короткими.

## Перед сабмитом

Сверяется с разделом «Блокирует допуск» в `TASKS.md` — там те же пункты с ответственными.

Первые четыре пункта — условия допуска, а не пожелания.

- [ ] Проект запускается с **чистого `git clone`** строго по README, на ноуте, где его не писали (п. 5.4.15–16)
- [ ] `docker compose up --build` работает **без `.env`** и без ключей (п. 5.6.6)
- [ ] `python scripts/verify.py` печатает `OK`
- [ ] README заполнен по всем разделам, включая «Использованные сторонние компоненты»
      и «Что было готово до начала соревновательной части» (п. 5.4.4, 5.4.4.2)
- [ ] `python scripts/dev.py check` зелёный
- [ ] `docs/HOURLY.md` заполнен за все пять часов, теги `h1`–`h5` запушены (п. 5.4.8)
- [ ] У всех троих есть коммиты под своим именем (п. 4.6)
- [ ] Видео-демо записано и лежит по ссылке — страховка от упавшего деплоя
- [ ] Развёрнуто по публичной ссылке, ссылка открывается с телефона, QR готов для слайда
- [ ] На публичном деплое `DJANGO_DEBUG=0` — иначе трейсбеки Django покажут настройки всем
- [ ] На публичном деплое `NEXT_PUBLIC_API_URL` указывает на реальный адрес бэкенда
      (значение вшивается при сборке образа — после смены нужен пересбор фронтенда)
- [ ] Ключи не в репозитории; если нужен настоящий ключ — подготовлен отдельный тестовый доступ
- [ ] Примеры данных реалистичны, казахстанский контекст — плюс
- [ ] Всё запушено **до 18:00**: то, что зафиксировано на этот момент, и есть итоговая версия (п. 5.4.13)
