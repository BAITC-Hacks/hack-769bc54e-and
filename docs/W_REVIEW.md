## Найденные и исправленные проблемы

- W3: backend возвращал только первые 8 отклонённых профилей из 10. Теперь возвращаются все;
  интерфейс ограничивает высоту раскрытого списка, сохраняя доступ к каждому кандидату.
- W2: заголовок второй выдачи зависел от редактируемого поля даты. Теперь он хранит дату
  отправленного запроса. При пустой первой выдаче кнопка скрытия доступна во второй.
- W5: у двух профилей код менял регистр цитаты, frontend добавлял многоточие. Теперь текст
  внутри кавычек — точная подстрока исходного описания. Регрессионный тест проверяет весь каталог.
- W6: добавлены пояснения происхождения плашек: синтетические профили взяты из датасета
  организатора, ориентировочные цена и город проставлены при подготовке данных.

## Как воспроизвести

Открыть локальное приложение. Город — Алматы, формат — свадьба:

1. Ведущий, 15.10.2026, бюджет 900 000. Скрыть/вернуть имена, проверить цитаты и журнал.
2. «А если другая дата?» → 26.12.2026. Сверить diff и сезонную заметку. Ввести 14.11.2026
   без отправки: заголовок второй выдачи должен остаться на 26 декабря.
3. Новый запрос: Ведущий, 15.10.2026, бюджет 400 000. Раскрыть список всех 10 отсеянных.
4. Ведущий, 05.12.2026, бюджет 900 000: 0 карточек. Сравнить с 15.10.2026:
   во второй колонке есть карточки и рабочая кнопка скрытия.
5. Банкетный зал, 24.10.2026, бюджет 3 000 000; Инструменталист, 15.10.2026,
   бюджет 1 000 000. Сверить плашки с `flags` в раскрытом ответе инструмента.
